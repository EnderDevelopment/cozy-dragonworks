# Fabric Minecraft Modpack: Cozy Dragonworks

Cozy Dragonworks is a curated Fabric Minecraft modpack for version 1.20.1, combining Create automation, Dragon Mounts: Legacy, Kaleidoscope Cookery, expanded structures, weapons and armor, and furniture and building mods for a cozy home-building adventure.

## Install

1. Install a launcher that supports Fabric, such as Modrinth App or Prism Launcher.
2. Create a Minecraft 1.20.1 instance with Fabric Loader 0.15.x (0.15.11 or newer in the 0.15 line).
3. Use `pack-manifest.json` as the mod list and install the Fabric 1.20.1 version of each selected mod. Allow the launcher to install required dependencies.
4. Choose either JEI or REI for recipe lookup; do not install both.
5. Launch the instance. The manifest is a curated list, not a launcher import file, and this repository does not include mod jars.

## Use

1. Create a new world after installing the mods. Structure generation is best experienced in a fresh world.
2. Build Create-powered machinery and a workshop, and use Kaleidoscope Cookery for expanded cooking and meals.
3. Explore dungeons, villages, towers, and larger adventure structures; find new weapons, ores, tools, and armor.
4. Hatch, tame, breed, and ride elemental dragons with Dragon Mounts: Legacy.
5. Furnish and decorate a home with the included furniture, decorative block variants, and utility blocks.
